# Methodology

## Fixed records
`reports/split_manifest.json` stores the training and test passenger IDs: 712 train and 179 test. Both classifiers use identical records and predictors.

Membership was originally fixed with the first fold of `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)`. Travel groups were connected components under either a shared normalized ticket or a shared (surname, reported family size) key for family sizes greater than one. This target-free grouping produced 671 groups, with the largest containing 8 passengers. It reduces known companion overlap but may miss related travelers or merge unrelated families. The stored membership is the reproducible input for the current analysis.

This partition was evaluated during earlier development. The current default-model comparison reuses it and does not claim a new independent or external test. No settings are adjusted to improve these test scores.

## Data preparation
1. Choose Age, SibSp, Parch, Fare, Pclass, Sex and Embarked.
2. Fill numeric gaps using training medians and categorical gaps using training modes.
3. Define categories from training records; one-hot encode and drop the first level. An unknown test category maps to zero indicators.
4. Fit StandardScaler on training numeric values and apply it to both partitions.

No rows are removed or resampled. Numeric scaling helps LR's regularization and avoids making GaussianNB's variance floor depend strongly on fare units. Both classifiers receive the same prepared features.

## Classifiers
- GaussianNB with default settings. It models class-conditional Gaussian feature densities under conditional independence. Counts and one-hot indicators are not Gaussian, and related features may violate independence; these are explicit approximation limits.
- LogisticRegression with default settings and `max_iter=1000` to allow convergence. It models survival probabilities with linear log-odds and L2 regularization.

There is no parameter search, probability calibration or threshold tuning in the current analysis. Predictions use survival probability >= 0.5. A training-majority prediction supplies a basic accuracy reference.

## Evaluation
Accuracy, survival precision, recall and F1 summarize threshold-based predictions. Undefined precision/recall use `zero_division=0`. ROC-AUC uses continuous survival probabilities to assess ranking; log-loss evaluates probability error. Confusion matrices use true labels as rows and predictions as columns, in class order [0, 1].

The report counts correct predictions and NB/LR disagreements directly from the predictions. Figures and tables are regenerated by `python titanic.py`. The small historical sample and a single previously inspected test partition limit generalization; small metric differences do not establish universal or statistically significant superiority.
